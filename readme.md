# 💰 Gestor Financeiro Pessoal

Sistema pessoal de controle financeiro desenvolvido em Python e SQLite.

O objetivo do projeto é registrar entradas e saídas de dinheiro, acompanhar o saldo e manter um histórico financeiro para ajudar no controle dos gastos, planejamento e economia.

> **Projeto pessoal — sem fins comerciais.**
>
> O sistema está sendo desenvolvido de forma incremental e será utilizado no dia a dia para controlar minhas próprias finanças.

---

## 🎯 Objetivo

O projeto nasceu da necessidade de ter um controle melhor sobre:

- Entradas de dinheiro
- Gastos
- Saldo disponível
- Histórico financeiro
- Categorias de gastos
- Planejamento financeiro
- Reservas financeiras
- Cartões e compras parceladas

A ideia é começar com uma versão simples pelo terminal e evoluir o sistema conforme novas necessidades forem surgindo durante o uso.
